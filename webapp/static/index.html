HOW TO GET YOUR BINANCE KEYS

1. Open Binance (App or Web) & search API Management.
2. Tap Create API → Select System Generated (HMAC).
3. Give it a label (e.g. CapoSniper) & verify 2FA.
4. Tap Edit & check: Enable Reading + Enable Spot & Margin (or Futures).
5. DO NOT enable Withdrawals (keep withdrawals off for 100% security).
6. Copy the API Key & Secret Key and paste above!
